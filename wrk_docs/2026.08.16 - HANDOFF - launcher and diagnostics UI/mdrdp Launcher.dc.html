The menu bar is drawn in the window so File / Connection / Diagnostics / Settings are identical on Windows and macOS. Each session is its own process and owns its own diagnostics windows. Every screen keeps the command line first-class: the wizard shows the equivalent mdrdp <host> invocation, and defaults set in Settings are the ones that command uses.
