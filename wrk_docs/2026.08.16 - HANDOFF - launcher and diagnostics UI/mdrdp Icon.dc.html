Three marks, shown at real icon sizes
Flat geometry only, in the palette the app now uses. Each row shows 512, 128, 64, 32 and 16 px on the dark backdrop and again on light, since the Windows taskbar and macOS dock both get used against either.
3a Two screens A remote display behind a local one. Reads as remote desktop with no text.
3b Hot cell The cache grid itself, one cell running hot. Distinctive; less obviously “remote desktop”.
3c Prompt The command line, since that is the thing you actually use. Survives 16 px best.
Only the app icon needs artwork — nothing in the launcher, wizard, settings or cache view depends on an icon set, so the build is not blocked on this.
