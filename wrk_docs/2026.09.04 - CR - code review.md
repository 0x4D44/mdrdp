### Regression work for the fix loop

- For 00126, force the ACK writer to fail first and assert a window-close notification plus a transport-failure result. Also prove intentional shutdown sends no extra notification. The existing [ACK failure test](~/language/mdrdp/src/native/session.rs:5640) observes stop, not the window or final result.
- For 00127, check both reply helpers against an oversized unterminated reply and a continuously drip-fed reply. Assert limit + 1 consumption at most and a total elapsed deadline; keep normal status, acknowledgement, and error replies valid.
- For 00128, inject failure at each auxiliary clone/thread-start boundary, especially after the writer starts. Assert worker exit, socket/outbox cleanup, and an unchanged main-session stop flag.

The filed bug uses the narrower, source-proven optional-channel failure path.
