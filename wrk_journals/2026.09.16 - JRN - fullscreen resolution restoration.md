# Fullscreen resolution restoration

Arthur reported Kiln remaining at 1920×1080 after a monitor power transition,
although the restored fullscreen desktop should be 2560×1440.

The running client was v0.1.249. Its session log recorded a 2560×1440 connection,
one 1920×1080 request, and subsequent reveal events, without a restoration request
or a full session-reactivation message. The shared graphics log also contained a
1920×1080 ResetGraphics, but lacks per-session attribution.

The window already checks its monitor once per second and requests fullscreen
resolution on reveal. The session duplicate check instead compares against the
activation-time desktop dimensions. EGFX ResetGraphics updates the graphics output
without updating those dimensions. This can discard the request that would restore
the original size. A second case needs coverage: restoration can be requested while
the preceding shrink is still in flight.

Tracked as MDR-BUG-FLU-00131. The fix reads the validated EGFX output dimensions
when a resize is pending and compares the requested layout with the last successfully
sent layout. Before the first graphics reset, legacy activation dimensions remain
the fallback. No polling or macOS event behavior changes.

Validation:

- `cargo test --locked --lib session::tests:: -- --test-threads=1`: 99 passed,
  including both RDP and native session tests selected by this filter.
- Three new tests cover EGFX-only restoration, restoration while a contrary resize
  is in flight, and suppression of a duplicate after a graphics reset.
- The worker and lead independently replaced the resize decision with the original
  activation-size-only comparison. All three regressions failed on their assertions;
  restoring the graphics-size comparison and last-sent guard returned them to green.
- The worker's `cargo clippy --lib --tests -- -D warnings` passed.
- `./scripts/check-windows.sh --locked` passed for mdrdp and the Rhydra host.
  Existing warnings remain for the unavailable Windows icon tool and unused
  `width`/`height` arguments in the Windows presenter.
- `cargo fmt --all --check` and `git diff --check` passed.

The designated live test host Quench was unreachable by DNS and its documented IP;
Anvil also failed DNS resolution. Kiln has an active user session. A disposable
geometry-only live probe was prepared and compiled, then removed without running:
permission to interrupt Kiln had not arrived. The fix changes local duplicate
suppression, not protocol encoding or negotiation. Live restoration and physical
monitor off/on remain unverified. The earlier monitor-policy bug MDR-BUG-FLU-00129
remains a separate closed record.
