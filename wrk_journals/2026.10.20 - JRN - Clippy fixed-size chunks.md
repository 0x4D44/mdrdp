# Clippy fixed-size chunk lint

- Claimed MDR-BUG-FLU-00132 in run `fix-20261020T225302Z-3c21586f`. On rustc/clippy 1.98.1, `cargo clippy --all-targets -- -D warnings` failed before the edit on `clippy::chunks_exact_to_as_chunks`: 32 calls across `src/` and `examples/` used constant chunk sizes.
- Replaced those calls with `as_chunks::<N>().0` and `as_chunks_mut::<N>().0` iteration. Complete fixed-size chunks are consumed and any incomplete tail remains ignored, matching the prior `chunks_exact` behavior. Updated the PCM comment to describe that behavior directly.
- The exact Clippy command passed after the changes. Formatting and the focused unit-test filters for audio, clipboard, dock, graphics, presentation, glass detection, and surfaces passed. `./scripts/check-windows.sh` also passed.
- Existing warnings remain in the vendored connector (`unfulfilled_lint_expectations`) and the Windows icon build step (icon file unavailable); neither was caused or changed by this work.
