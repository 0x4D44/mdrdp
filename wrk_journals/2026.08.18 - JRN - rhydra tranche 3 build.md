## Understanding pass (two parallel code maps, findings that shaped the design)

- mdrdp's window shell is already transport-agnostic (`window.rs` imports no
  ironrdp); the seam is a four-handle contract: `SurfaceStore` + `Waker` +
  `WakingSender<InputEvent>` + `SessionCommand` + `StatsHandle`. Branch point
  for `--native` is the `establish` call at `src/main.rs:747`.
- `spike-viewer` depends on mdrdp by path, so lib reuse is a cycle: the
  viewer's net/sink logic ports INTO `src/native/`; mdrdp takes portable
  `rhydra` as a path dependency (framing/rects/control/input_proto; its
  windows deps are cfg-gated — verified in its Cargo.toml).
- Real scope discovery: the spike input channel is keyboard-VK-only. An MVP
  session needs mouse + full scancode map → input protocol v2 + server
  SendInput work + wire_version 3.
- SSH auth: deploy's `Ssh` uses one-shot `ssh` with no BatchMode; a GUI
  session needs key auth (BatchMode) — quench needs a key installed as host
  config (administrators_authorized_keys).

## Review round (2026-08-19, small hours): the strongest yield of the flow so far

Both Opus seats returned (no 529s this time). Six criticals between them,
every one construction-verified against the code, all folded:

- Probe `green` is optimistic by the agent's own design — the transport
  decision now commits only on the session sockets themselves (control is a
  pre-filter; video connect + header gate + input connect, all inside the
  Auto fallback window, one 8 s deadline).
- The forward-readiness race (ssh binds -L only after auth): ECONNREFUSED
  means retry, with try_wait short-circuit.
- The probe's version check was the wrong version domain (agent crate vs
  server wire); deleted — the header's wire_version is the single gate.
- Auto probed hosts that never opted in (Security-log noise, domain lockout
  risk): deploy now writes a local host record and Auto probes only
  recorded hosts.
- Auto's RDP fallback could console-kick a live native session on the same
  host: presence gains a transport field and the fallback is guarded.
- The SSH-key story pointed at a checklist that doesn't exist: deploy's
  verify gains a BatchMode probe with an actionable warning; key install
  stays manual, documented.

Majors of note: the "store is the canvas" plan silently reintroduced the
8 MB-per-AU copy the spike had explicitly removed (fix: `adopt_pixels` /
`pixels_mut` zero-copy surface API); the input thread's bare `recv()` would
deadlock the join (window holds the sender); DPI-unaware server metrics +
a discarded display origin would skew every click; rhydra's `win` module
would link a keystroke injector into the Windows client binary (fix: `host`
feature). Full record in the HLD §11. Marked SELF-APPROVED; implementing.
