# MDR-BUG-FLU-00125 — scripted duration shutdown

The 0.1.237 report records a successful Quench connection and audio negotiation, then a separate `--duration 8` run that was killed by a 60-second guard without metrics or graceful-shutdown evidence. It does not identify the transport or show which operation stalled. No live session was retried in this drain; Quench had no active viewer when checked, and the available native probe stopped at its display-status timeout before opening a viewer.

The shared exit hook had one concrete unbounded operation before session shutdown: it removed presence and loaded and saved remembered window state first. `SessionState::save_to` performs filesystem writes and `sync_all` synchronously. A stalled filesystem can therefore hold the event loop in its exit callback before the RDP or native handle even starts shutdown.

The exit hook now takes and shuts down the active session before presence removal and state persistence. A gated regression stalls the best-effort I/O callback and checks that disconnect completes before that callback starts. The regression failed when the helper was temporarily changed to the old I/O-first order, then passed with the fix restored.

Focused evidence:

- `deltic timeout 60 cargo test --bin mdrdp`: 19 passed.
- `MDRDP_GUI_TESTS=1 deltic timeout 60 cargo test --test macos_menu_lifetime`: passed; the probe closes from a worker thread and observes the exit hook.
- `cargo fmt --all -- --check`: passed.
- `deltic timeout 60 cargo clippy --bin mdrdp --tests -- -D warnings`: passed. Cargo still reports the existing unfulfilled `single_use_lifetimes` lint expectation in vendored `ironrdp-connector`.

The injected regression demonstrates that stalled best-effort persistence no longer delays the disconnect path. It does not establish that this was the operation that stalled in the historical 0.1.237 run, nor does it put a deadline on session-worker joins. The RDP and native worker joins remain synchronous; their exact role in the historical observation is unknown.
