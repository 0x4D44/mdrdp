- One winit EventLoop per process; reuse via `run_app_on_demand` (lessons_learnt).
- Never `{:?}` an ironrdp `Config`/`Credentials`.
- Live-connect budget: prefer quench (`ano` account, memory note) over temper; always
  graceful shutdown.
- Run test suites with stdin closed (`</dev/null`).
